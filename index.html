How Spam Detection Works 🧠

Inside the ML flow

STEP 1

User Input

User enters a message or email.

↓
STEP 2

Text Preprocessing

Clean unnecessary characters and prepare the text.

↓
STEP 3

TF-IDF Vectorization

Convert text into numerical features.

↓
STEP 4

Machine Learning Model

Use a classification algorithm such as Multinomial Naive Bayes.

↓
STEP 5

Prediction

Model predicts: SPAM or SAFE

↓
STEP 6

Result

Display prediction and confidence to the user.

About Spamly 💜

Built for learning, safety, and awareness

Spamly is a student machine-learning project designed to demonstrate how text classification can be used to identify potentially unwanted messages and emails.

Project Objective

  • Detect spam messages
  • Detect suspicious emails
  • Demonstrate text preprocessing
  • Demonstrate TF-IDF
  • Demonstrate machine learning classification
  • Provide basic online safety education

Technologies

  • Frontend: HTML
  • CSS
  • JavaScript
  • Responsive Design
  • LocalStorage
  • Fetch API ready for future backend
